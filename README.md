# Arc Runner

A lightweight, mobile-friendly endless runner. Tap to jump, collect glowing Arc Energy, and dodge obstacles and gaps as the pace picks up. It runs entirely in the browser with no backend or external APIs.

Built with [Arc Studio](https://studio.arc.io)

## Features

- Tap anywhere (or press Space, Up or W) to jump
- Score goes up for every Arc Energy orb collected
- Speed increases the longer you survive
- Three difficulty levels (Spark, Surge, Overdrive) that unlock as your best score grows
- Best score, difficulty and sound preference saved in your browser
- Sound toggle with built-in synthesized effects

## Tech stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion, HTML canvas

## Development

Prerequisites: [Bun](https://bun.sh)

```bash
bun install
bun run dev
```

Other commands:

```bash
bun run build
bun run check
```

### Environment variables

None.
